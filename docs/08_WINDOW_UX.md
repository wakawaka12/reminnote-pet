# 08 · 悬浮窗交互与无障碍规格

> 本文定义桌宠悬浮窗的**窗口形态、交互方式、状态迁移、无障碍**。实现参考主程序
> `WidgetWindow` 的无边框透明形态（`WindowStyle=None / AllowsTransparency / WindowChrome`），
> 交互细节为本模块特有。

## 1. 窗口形态

- `WindowStyle="None"`、`AllowsTransparency="True"`、`Background="Transparent"`；
- `Topmost="True"`（桌宠置顶，可被用户/设置调整）；
- `ShowInTaskbar="False"`（常驻角色，不用任务栏占位；托盘承载真实入口）；
- `ResizeMode="NoResize"`（角色尺寸固定，避免拖拽变形）；
- `WindowStartupLocation="Manual"`（位置由本地持久化恢复）；
- 用 `WindowChrome` 去掉系统标题栏/边框（对齐 `WidgetWindow`）。

## 2. 四个视觉状态

| 状态 | 尺寸/表现 | 交互 |
|------|-----------|------|
| **待机 `Idle`** | 小型角色（约 120×120 DP），低帧动画 | 拖拽移动；单击弹「气泡+动作」；双击/点击展开面板；拖到边缘吸附 |
| **提醒 `Alert`** | 角色+气泡出现，播 `alert` 动画 | 显示未读提醒；按钮：`完成 / 稍后 / 忽略 / 打开主程序`；按优先级强提醒 |
| **展开 `Expanded`** | 弹出小面板（Today/Anime 精简 + Reminder Drawer） | 复用 Widget 的面板交互（只读为主，写经命令） |
| **收纳 `Collapsed`** | 角色缩小/半透明/隐藏 | 只保留托盘；动画暂停；可随时唤醒 |

## 3. 交互细则

### 3.1 拖动与边缘吸附
- **拖拽**：按住角色（非按钮区）拖动；`MouseLeftButtonDown` 记录偏移，`MouseMove` 更新位置；
  释放后**吸附到屏幕边缘**（若靠近某边），并持久化位置（本地状态文件，见 `04_REMINDER_MODEL` §6）。
- 吸附边界遵循 Windows 多显示器虚拟屏幕，避免跨屏卡死。
- 收纳态：点击托盘图标还原到上次位置。

### 3.2 提醒气泡与动作
- 触发 `Alert` 时，动画播放 + 气泡浮现（`AutomationProperties.LiveSetting="Polite"`）。
- 气泡含：提醒标题/正文（来自 `ReminderSnapshot`）、目的标签（如「任务即将开始」）、
  动作按钮 `完成 / 稍后 / 忽略 / 打开主程序`。
- LOW/NORMAL 后到先计；若多条，合并为「有 N 条待提醒」摘要，避免刷屏（对齐主程序 `#17`）。

### 3.3 与托盘的关系
- **关窗 = 收纳**（`Close` 不退出进程，隐藏窗口 + 暂停动画 + 保留托盘）。
- 托盘菜单：`显示桌宠 / 收纳 / 静音提醒 / 打开主程序 / 退出`。
- 真正的退出仅在托盘「退出」；避免误关导致桌宠消失但提醒丢失。

## 4. 无障碍（对齐主程序 P0-07 门槛）

- 关键交互控件（角色、气泡、每个动作按钮）设置 `AutomationProperties.Name` / `HelpText`（中文）。
- 共享焦点令牌 `AccessibleFocusBrush`，保证键盘焦点**清晰可见**。
- 键盘导航：`Alt+Tab` 不适用（无任务栏项），但提供**托盘快捷键**与**Tab 焦点**在气泡内循环；
  `Esc` 收起气泡，`Enter/Space` 触发主动作。
- 动画**不是唯一信息载体**：文字始终存在；减少动效偏好下第 7 节降级规则生效。
- 屏幕阅读器可读：气泡内容、动作，以及状态变化（`LiveSetting`）。

## 5. DPI 与多显示器

- 使用 `SnapsToDevicePixels` / `UseLayoutRounding`；素材按 2x/3x 提供以适配高 DPI。
- 多显示器：吸附边界为**虚拟屏幕**；跨屏拖动不丢失；高 DPI 下角色尺寸稳定。
- 保留 `resizing` 限制与 `content` 缩放（对齐主程序既有 polish 约束）。

## 6. 键盘焦点与模态
- 气泡为轻量**非模态**覆盖？——建议**非模态**（不阻挡桌面其它操作），但提醒气泡默认置顶。
- 展开面板可模态；收起后焦点归还（避免焦点丢失）。

## 7. 减少动效 / 高对比降级

| 系统偏好 | 桌宠行为 |
|----------|----------|
| `reduced motion` | 停止序列帧推进，改用**静态角色 + 非动画气泡**；减少缩放/位移 |
| `high contrast` | 回退为**不透明**背景、高对比文字，隐藏透明渐变 |
| `reduced transparency` | 关闭透明背景，使用实心底面 |

> 这些降级确保「提醒的**语义**永远可达」，动画只是锦上添花。
